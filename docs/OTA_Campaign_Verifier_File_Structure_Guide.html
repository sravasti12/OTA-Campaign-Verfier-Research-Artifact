3. Execution path and trust boundaries

Documents + authoritative ECU inventory
↓
LLM extraction → schema / exact source checks → LLM faithfulness gate
↓ when ready
Z3 planning → independent concrete plan validation
↓ when feasible
Deterministic fault sweep → invariants → authorized recovery
↓
Engineering evidence + advisory explanation → explicit human review

Only extraction, faithfulness and advisory explanation can use a model. Compatibility, scheduling, simulation, policy comparison and approval eligibility are deterministic code. LangGraph orchestrates stages and pauses; it does not replace their rules.
